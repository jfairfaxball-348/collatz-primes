# Collatz Primes

**Mission:** Investigate the interaction of primality, compositeness and the shortened Collatz map, with the headline objective of proving that every composite positive integer reaches 1. This goal is *equivalent* to the full Collatz conjecture: for any prime `p`, the composite `2p` maps directly to `p`.

Map: `T(n) = n/2` for even `n`; `T(n) = (3n+1)/2` for odd `n`.
