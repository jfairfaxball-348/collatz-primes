# Evidence, novelty and publication gates

A theorem over all positive integers requires a universal mathematical proof, not large tests. Precisely classify every item:

- PROVED_INTERNAL: complete proof written in this repository. It may be elementary or known; originality is separately evaluated.
- SOURCE_STATED: a statement read from a named dated primary source; verify exact domain, notation and hypotheses.
- FINITE_TEST: executable check with finite domain, exact code and preserved outputs; this does not promote the proposition to an infinite claim.
- CONJECTURE / OPEN: not proved.
- REFUTED: specify counterexample and failing quantifier.
- FORMAL_VERIFIED / PALOMAR_VERIFIED: only when a matching actual completed formal artifact or external verification exists.

Do not conflate count of convergent primes/composites, stopping-time distributions, density-one theorems, bounded modular tests or a verified integer frontier with total convergence.

Every route must pass:
(1) well-definedness; (2) logically noncircular reduction; (3) quantified proof; (4) counterexample audit; (5) prior-art check; (6) appropriate formal / independent check if a substantial new result warrants it.
Publish or present as original only after a credible novelty review and independent evaluation. Do not claim priority prematurely.
