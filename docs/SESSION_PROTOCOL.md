# Research session protocol (one session per owner invocation)

## Entry / source authority
1. Read the current exact owner instruction. If it supplies/links a prompt and requests action, that authorises **the named session itself**, without a redundant separate confirmation. Never execute S### + 1 automatically.
2. Independently inspect the live GitHub main commit and tree, current branch, open/recent merged PRs, workflows/check runs when available, and any known rulesets. Record unavailable checks as NOT OBSERVED, not PASS.
3. Read AGENTS.md; authoritative START_HERE, STATE, NEXT_SESSION_PROMPT; docs/EVIDENCE_POLICY; current research claims, questions, sources and failure log; previous session closeout. Resolve conflicting records explicitly.
4. Open a unique S### with input context and a bounded plan. Archive user-supplied exact instructions if available; never invent a SHA-256 for uncaptured bytes.

## Work / discovery
5. Prioritise a legitimate route to the global theorem. Try several attacks; include an explicit falsification step for every attractive assertion and independent algebraic spot checks for new formulas.
6. Each proof states its quantifiers, definitions, lemmas and full justification. Be alert that multiplication, factorization, density-one statements and experiments do not commute with Collatz dynamics.
7. Computational work must be exact where feasible, versioned, finite-bound stated, reproducible (commands, inputs, outputs), and distinguish stopping at 1 from hitting a smaller number. Avoid treating execution caps as divergence proofs.
8. Maintain numbered claim IDs with classifications: PROVED_INTERNAL, SOURCE_STATED, FINITE_TEST, CONJECTURE, REFUTED or OPEN. External prior-art novelty remains UNCHECKED unless actually established.

## Close / publication
9. Update state, claims, sources, failure ledger, session ledger, mathematical note and full session closeout. Disclose test environment, discrepancies, missing independent audits and main theorem's actual status.
10. Write the COMPLETE next numbered prompt in authoritative/NEXT_SESSION_PROMPT.md and in the closeout or link to an exact same-revision file explicitly as a full copy. Label it FUTURE/UNEXECUTED. Do not install a second-confirmation gate.
11. Prefer one coherent single-parent authored commit on a dedicated session branch, a PR, ordinary nonforce merge and independent postmerge remote SHA/tree verification. If permissions or protection block merge, leave PR open and report precise blockage. Do not fabricate successful checks.
12. Return a readable report: new proven mathematics; falsifications/negative findings; finite-only evidence; full limitations; verified GitHub PR, merge and next-session prompt links.
